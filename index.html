04WORLD / LORE

战姬世界

根据现有故事文档整理的全年龄版世界观。

THE CORE SYSTEM

光之战姬以「晶核」维系力量，并通过能量灯呈现自身状态。能量既是战斗与变身的燃料，也能够在战姬之间传递，用于治疗、修复与支援。

ENERGY

能量与晶核

晶核是战姬力量系统的核心。能量过度消耗会影响战斗与变身，而医疗型战姬能够通过自身能力帮助同伴恢复。

CLASS

战姬分工

战姬拥有不同的能力倾向。零属于战斗型，以寒冰系能力和正面作战见长；蕾蕾则偏向医疗与支援，拥有出色的治疗能力与能量储备。

ORDER

组织

组织以任务、监视和纪律约束战姬，对叛逃者采取极端惩罚。零曾是组织锋利的执行者之一，而蕾蕾因无法接受其制度选择逃离。

WILD

坏兽与荒野

组织之外同样并不安全。荒野中的坏兽会袭击战姬，毒素与能量污染也会削弱她们，因此战斗、治疗和净化缺一不可。

MAIN STORY

从追捕到并肩逃亡

  1. 01
    追捕

    冰刃零奉组织命令追捕叛逃的蕾蕾。

  2. 02
    救援

    两人在荒野遭遇危机，蕾蕾以医疗能力救下原本追捕自己的零。

  3. 03
    动摇

    零开始怀疑自己一直相信的组织秩序，并逐渐理解蕾蕾逃离的原因。

  4. 04
    选择

    在组织与彼此之间，两人最终选择互相保护。

  5. 05
    脱离

    她们不再是追捕者与叛逃者，而是一起离开组织，寻找属于自己的自由。
